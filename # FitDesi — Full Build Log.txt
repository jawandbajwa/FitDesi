## Project Overview

FitDesi is a personal fitness web app for Indian vegetarian body recomposition. It tracks workouts, macros, and meals with a full recipe cookbook covering both Indian and Canadian cuisines.

**Goal:** Body recomposition — lose fat and build muscle simultaneously  
**Diet:** Pure vegetarian, no eggs, no meat  
**Supplement:** Diesel NZ Whey Isolate (Perfect Sports, 27g protein per scoop)  
**Split:** 5-day rolling cycle (Chest+Tri / Back+Bi / Legs+Core / Shoulders+Abs / Light Cardio)

|---|---|---|

## Macro Calculator Formula

**BMR** (Mifflin St Jeor):
- Male: `10 × weight + 6.25 × height − 5 × age + 5`
- Female: `10 × weight + 6.25 × height − 5 × age − 161`

**TDEE** = BMR × activity multiplier (1.2 / 1.375 / 1.55 / 1.725)

**Goals:**
- Recomp: 95% TDEE, protein = weight × 2.2g
- Muscle: 110% TDEE, protein = weight × 2.0g
- Fat Loss: 85% TDEE, protein = weight × 2.4g

**Body Fat** (US Navy Formula):
- Male: `495 / (1.0324 − 0.19077 × log10(waist − neck) + 0.15456 × log10(height)) − 450`

## Meal Planner Algorithm

1. Get daily macro targets from profile
2. If "Fill Remaining" mode — subtract already consumed from targets
3. Load recipes from selected cuisine (Indian or Canadian)
4. Sample up to 5 recipes from each category (random)
5. Score every combination of breakfast + lunch + dinner + snack:
   - `score = |protein diff| × 3 + |carbs diff| × 1 + |fat diff| × 1.5 + |calories diff| × 0.5`
6. Pick lowest score combination
7. Allow user to swap individual meals
8. Confirm → write to Firebase daily log
